# v0.4.1 — A little breathing room

## Highlights

- Rebuilt the microsite around a clean-air visual identity: mist white, deep
  teal, and a custom SVG/canvas airflow illustration.
- Added real-renderer screenshots of the dashboard, history, theme picker,
  Nord, and Catppuccin. All captures use explicitly labeled synthetic data.
- Added keyboard-accessible screenshot navigation and theme previews, copyable
  commands, compact installation steps, and native FAQs.
- Added motion controls, reduced-motion support, and offscreen/hidden-tab
  animation suspension. Essential content remains usable without JavaScript.
- Shortened the README and moved the full technical reference to `docs/usage.md`.
- Added reproducible screenshot tooling and browser/accessibility checks in CI.

## Compatibility

This is a documentation and website patch release. The v0.4.0 TUI, CLI commands,
sensor parsing, thresholds, configuration, and history behavior are unchanged.
There are no runtime dependency changes.

## Validation

- Rust 1.96.0: formatting, strict all-target/all-feature Clippy, and 435 tests pass.
- Real pseudo-terminal coverage exercised; no conditional PTY skips.
- cargo-deny 0.19.9: advisories, bans, licenses, and sources pass.
- Linux amd64 and arm64 release builds and local archive/checksum rehearsals pass.
  The local arm64 rehearsal was cross-compiled with Zig, not executed on arm64
  hardware. GitHub Actions uses the GNU cross toolchain for published arm64 assets.
- Chromium checks pass at 320, 390, 768, 1024, 1440, and 1920 pixels, including
  keyboard navigation, clipboard success/denial, no-JS content, blocked storage,
  motion controls, and reduced motion. Automated axe-core WCAG A/AA checks pass.
  This does not replace human screen-reader testing.
- Screenshot generation verifies font glyph coverage, dimensions, current source
  hashes, and PNG integrity. Captures are not live hardware readings.
- Real-device validation waiver: no live AirGradient hardware run was performed.
  Synthetic fixtures, mock HTTP devices, and real pseudo-terminals are not a
  hardware-compatibility guarantee.

## Distribution

GitHub Actions publishes this Linux-only, binary-only, MIT-licensed release for
amd64 and arm64. Archives include the executable and LICENSE; SHA256SUMS covers
the archives, and install.sh is the convenience installer. Artifacts are
unsigned. No crates.io package, macOS/Windows binary, package-manager recipe,
or shell completion artifact is included.
