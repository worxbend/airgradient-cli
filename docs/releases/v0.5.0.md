# v0.5.0 — Air quality in Waybar

## Added

- `airgradient-cli --waybar` prints one compact JSON object for a Waybar
  custom module: every reading in `text`, the device URL and each status in
  `tooltip`, the worst hazard status in `class`, and the AQI in `percentage`
  when the device sent one.
- A missing sensor stays `--`. Temperature and humidity are shown and do not
  set `class`.
- A failed `--waybar` fetch still prints JSON and exits 0, so the bar can
  update. A saved reading is marked `stale`. No saved reading, or no
  configured device URL, uses `offline`.

## Changed

- Updated `rustls` to 0.23.46, `rustls-webpki` to 0.103.16, `tokio` to
  1.54.1, and `webpki-roots` to 1.0.12. This clears the RustSec advisories
  that made `cargo deny check` fail on the previous lockfile.

## Compatibility

`--waybar` is new. The one-shot table, `--json`, config commands, sensor
parsing, thresholds, and the shared desktop config path are unchanged. Text
output and `--json` still exit 1 when a fetch fails.

## Validation

- Rust 1.96.0: formatting, strict all-target/all-feature Clippy, and `cargo test` pass.
- Real pseudo-terminal coverage exercised; the PTY suite was not skipped.
- cargo-deny 0.19.9: advisories, bans, licenses, and sources pass. One unmatched
  `windows-targets@0.53.5` skip warning remains; it does not fail the check.
- Local amd64 dry run staged
  `airgradient-cli-v0.5.0-x86_64-unknown-linux-gnu.tar.gz` with `LICENSE` and
  `SHA256SUMS`. The binary was not run against a device.
- Local arm64 dry run did not build. This machine has Zig and no
  `aarch64-linux-gnu-gcc`, and `ring` rejected Zig's target triple. GitHub
  Actions builds the published arm64 asset with the GNU cross toolchain. That
  binary was not executed here.
- Real-device validation waiver: no live AirGradient hardware run was
  performed. Synthetic fixtures and mock HTTP devices are not a
  hardware-compatibility guarantee.

## Distribution

GitHub Actions publishes this Linux-only, binary-only, MIT-licensed release for
amd64 and arm64. Archives include the executable and LICENSE; SHA256SUMS covers
the archives, and install.sh is the convenience installer. Artifacts are
unsigned. No crates.io package, macOS/Windows binary, package-manager recipe,
or shell completion artifact is included.
