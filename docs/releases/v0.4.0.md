# v0.4.0 — Terminal cockpit redesign

## Highlights

- Redesigned the dashboard with an oversized AQI readout, layered telemetry cards,
  semantic status badges, banded gauges, sparklines, and responsive layouts.
- Unified history, theme selection, configuration, command palette, keyboard help,
  notifications, and startup presentation around shared visual components.
- Added semantic surfaces and interaction states across all palettes, including
  monochrome, with readable keyboard hints and selection feedback.
- Improved short-terminal selection visibility, mouse hit mapping, and long
  Unicode input editing without changing command grammar or sensor thresholds.
- Added a deterministic, synthetic-data preview gallery generated from actual
  Ratatui buffers, with cross-theme, resize, and keyboard regression coverage.
- Removed obsolete slider/toaster dependencies and their unused transitive packages.

## Other changes since v0.3.0

- Give every queued air-quality alert its own display time.
- Report all startup problems, repaired configuration fields, and the specific
  metric whose history lacks enough readings.
- Simplify metric roster, sensor scale, history replay, and list navigation internals.
- Update Rustls to 0.23.45 (and rustls-webpki to 0.103.15), addressing
  RUSTSEC-2026-0285 without a broad dependency refresh.

## Validation

- Rust 1.96.0: formatting, strict all-target/all-feature Clippy, and 435 tests pass.
- Real pseudo-terminal coverage exercised; no conditional PTY skips.
- cargo-deny 0.19.9: advisories, bans, licenses, and sources pass.
- Linux amd64 and arm64 release builds and local archive/checksum rehearsals pass.
  The local arm64 rehearsal was cross-compiled with Zig; it was not executed on
  arm64 hardware. GitHub Actions builds the published arm64 binary with GNU tools.
- Real-device validation waiver: no live AirGradient hardware run was performed
  for this release. Validation uses synthetic fixtures, mock HTTP devices, and
  real pseudo-terminals; this is not a hardware-compatibility guarantee.

## Distribution

GitHub Actions publishes this Linux-only, binary-only, MIT-licensed release for
amd64 and arm64. Both archives include the executable and LICENSE. SHA256SUMS
covers the archives; install.sh is the convenience installer. Artifacts are
unsigned. No crates.io package, macOS/Windows binary, package-manager recipe,
or shell completion artifact is included.

See [the design system](../tui-design.md) for component contracts and preview usage.
