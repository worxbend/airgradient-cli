# v0.6.0 — Choose the Waybar metrics

## Added

- `--waybar-format` fills Waybar `text` from named readings. Waybar 0.16 only
  substitutes `{text}`, `{alt}`, `{icon}`, and `{percentage}`, so the template
  lives on the command and Waybar's `format` stays `{}`.
- Placeholders: `{aqi}`, `{co2}`, `{pm25}`, `{pm2p5}`, `{pm2.5}`, `{pm1}`,
  `{pm1.0}`, `{pm10}`, `{pm03}`, `{pm03_count}`, `{tvoc}`, `{nox}`, `{temp}`,
  `{temperature}`, `{temperature_c}`, and `{humidity}`. A missing sensor stays
  `--`. `{temp}` includes the unit.
- `class` follows the named metrics. Temperature and humidity set `class` only
  when the template names no hazard metric. `percentage` is the AQI, and only
  when the template names `{aqi}` or the template is omitted.
- An unknown or unclosed placeholder exits 1 and prints no JSON. A failed
  fetch still exits 0: the same template on a saved reading, marked `stale`,
  or `offline` when there is nothing to show.

## Compatibility

The default `--waybar` line is unchanged: every reading, the worst hazard
status in `class`, and AQI `percentage` when the device sent one. The one-shot
table, `--json`, config commands, sensor parsing, thresholds, and the shared
desktop config path are unchanged. Text output and `--json` still exit 1 when
a fetch fails.

- Real pseudo-terminal coverage exercised; the PTY suite was not skipped.
- cargo-deny 0.19.9: advisories, bans, licenses, and sources pass. One unmatched

- Local amd64 dry run staged
  `airgradient-cli-v0.6.0-x86_64-unknown-linux-gnu.tar.gz` with `LICENSE` and
  `SHA256SUMS`. The binary was not run against a device.
- Local arm64 dry run did not build. This machine has no

  a native arm64 runner. That binary was not executed here.
- Real-device validation waiver: no live AirGradient hardware run was
  performed. Synthetic fixtures and mock HTTP devices are not a
  hardware-compatibility guarantee.

## Distribution

GitHub Actions publishes this Linux-only, binary-only, MIT-licensed release for
amd64 and arm64. Archives include the executable and LICENSE; SHA256SUMS covers
the archives, and install.sh is the convenience installer. Artifacts are
unsigned. No crates.io package, macOS/Windows binary, package-manager recipe,
or shell completion artifact is included.
